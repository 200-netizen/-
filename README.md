# Green Corner — навчальний проєкт GitHub + GA4 + Clarity

Це простий адаптивний сайт українською мовою для навчального завдання. Бренд Green Corner вигаданий; сайт не приймає справжні замовлення.

## Файли
- `index.html` — структура сайту та місця для кодів GA4 і Microsoft Clarity.
- `style.css` — оформлення та адаптація до мобільних пристроїв.
- `script.js` — інтерактивні кнопки й демонстраційна форма.

## 1. Опублікувати на GitHub Pages
1. Увійдіть у https://github.com/.
2. Створіть новий репозиторій, наприклад `github-ga-clarity`.
3. Завантажте в репозиторій ці три файли (`index.html`, `style.css`, `script.js`) та цей README.
4. Відкрийте **Settings → Pages**.
5. У розділі Build and deployment виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, потім натисніть **Save**.
6. Дочекайтеся публікації та відкрийте URL, який GitHub Pages покаже в налаштуваннях.

## 2. Підключити Google Analytics 4
1. Відкрийте https://analytics.google.com/ і створіть GA4 property.
2. Додайте вебпотік для опублікованого URL сайту.
3. Скопіюйте Measurement ID формату `G-XXXXXXXXXX`.
4. У `index.html` знайдіть `GOOGLE ANALYTICS 4`.
5. Розкоментуйте відповідний блок: приберіть `<!--` перед ним і `-->` після нього.
6. Замініть обидва входження `G-XXXXXXXXXX` на власний Measurement ID.
7. Збережіть зміни та завантажте оновлений `index.html` у GitHub.
8. Перевірте дані через Realtime у GA4. Збір даних може початися не миттєво.

## 3. Підключити Microsoft Clarity
1. Відкрийте https://clarity.microsoft.com/ і створіть проєкт.
2. Вкажіть URL опублікованого сайту.
3. Скопіюйте Project ID / tracking code з налаштувань Clarity.
4. У `index.html` знайдіть `MICROSOFT CLARITY`.
5. Розкоментуйте блок Clarity і замініть `CLARITY_PROJECT_ID` на свій ID.
6. Збережіть і завантажте оновлений файл у GitHub.
7. Відкрийте опублікований сайт, взаємодійте з ним і згодом перевірте Clarity. Записи та теплові карти можуть з'явитися із затримкою.

## 4. Що перевірити перед здачею
- Сайт відкривається за публічним URL GitHub Pages.
- Усі секції навігації працюють.
- Кнопки в каталозі показують повідомлення.
- Демонстраційна форма показує повідомлення й не надсилає дані.
- GA4: збережіть скриншот вебпотоку та/або звіту Realtime після появи даних.
- Clarity: збережіть скриншот налаштувань проєкту та, коли дані з'являться, теплової карти або запису сесії.
- Додайте URL сайту та URL репозиторію до здачі.

## Важливо
Ідентифікатори GA4 і Clarity у шаблоні — це лише заповнювачі, а не справжні коди. Інструменти аналітики не почнуть збирати дані, поки ви не створите власні проєкти й не вставите справжні ідентифікатори. Не публікуйте в репозиторії паролі чи інші секретні дані. Перед використанням аналітики на реальному сайті перевірте вимоги щодо повідомлення про cookies/аналітику та конфіденційності.
